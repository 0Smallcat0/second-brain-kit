# Outside resources (外部資源)

What the user has besides this Claude account, and which one does which kind of work.
Filled by the user's Claude at install, from the setup question where the user ticked what they
have: only ticked items go in, nothing is assumed. Re-checked every month (Full: alarm row T01 to
the maintenance session) and whenever a new model comes out: which resource is best for each kind
of work changes, so this table, not the kit, says what does what. Look here before sending a job.
Rules and the monthly check: the kit's docs/MULTI-TOOL.md.

## What the user has

類型 = other AI (another AI account or web chat), compute (GPU / notebooks), credits and services
(cloud credit, student offers, API credit). "可免費申請" marks one the user could sign up for free
but has not; it is not used until the user says they signed up.

| 類型 (type) | resource | account / plan | how to call | limits / locked until | tested on |
|---|---|---|---|---|---|

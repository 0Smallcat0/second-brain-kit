# 它平常幫你做什麼

[English](../GUIDE.md) · [回到說明首頁](../../README.zh-TW.md)

基本款做什麼、裝好就有什麼和會越用越長什麼、怎麼用，以及 Claude 什麼時候建議加開。從說明首頁搬來，文字不變。

## 基本款能幫你什麼

基本款是一定會裝的那一份。和單純用 Claude Code 比起來：

- **筆記換了對話也找得回來。** 今天說「記住這個」，下個月開一個全新的對話也找得到。每件事動手前，Claude 先查筆記。
- **一份追蹤表**（`ledger.py`）。還沒做完的事 Claude 會記下來，你不用自己記。它要附上怎麼確認的，才會關掉一件事；這份證據是給之後核對的對話看的，不是給你看的：你只拿到結果。
- **做完檢查：提醒 Claude 先看結果再說「做完」。** 它沒看結果就說做完時，基本款會記下來，但不會攔住它（想讓它直接被攔下，之後可以再開）。
- **做有風險的事之前先問你。** 要推上遠端、刪掉整個資料夾、丟掉 git 裡的工作、跳過 git 檢查、改受保護的規則檔，或把一張筆記砍到剩一小部分之前，Claude 會先停下來問你。只刪或搬一張筆記，由 Claude Code 自己的權限詢問處理；對筆記的每次修改都會記進筆記資料夾自己的修改紀錄，改壞了可以找回舊版本。
- **聊太久時，把你的原話補回去。** 對話太長時，Claude Code 會自動把舊的內容濃縮成摘要，細節可能不見；這套工具會把你自己打的訊息原文補回去，降低你的要求被漏掉的機會。對話長到一定程度，Claude 會寫好交接，請你開新對話；新對話自己會找到交接，你不用說任何話。
- **Claude 會從你身上學（你給骨架，用久了長出血肉）。** 你糾正它、或確認它做對時，一個小檢查（`learn_notice`）提醒它在一張筆記（〈和 AI 協作〉：日期、你的原話、是哪一類事）記一行。每週第一次開對話時，它把這些紀錄照類別整理，提出偏好（同一種錯一直出現時，再提技能或檢查）；你說好才寫進去。每個新對話一開始就帶著這些偏好（同一個檢查放進去的），動手前再看最近的紀錄。

## 裝好就有的，和會越用越長的

**裝好就有（不用先學）：**
- **做事的原則。** 你同意後，設定時會在 Claude 給所有專案用的規則裡加一小段：在實際規則內替你爭取最大利益、不加你沒開口要的警告和但書、看做成了什麼而不是說了什麼、不捏造來源和「做完了」。同時放進 Claude 每次回覆前要對一次的四種失誤：還沒做完就說做完；同時有幾件事時只顧一件、漏掉另一件；遇到問題只指出來就停手；手上有資料卻不讀。
- **12 條起始偏好**，放在〈和 AI 協作〉那張筆記：原作者整理的通用做法（例如：把事情準備到只剩你的最後一步；只改你要改的地方並說改了什麼；要你動手時給一份編號清單）。每一條結尾都寫著「（來自原作者，可刪）」，第一個對話就會照著做。不合你的就刪掉那一行，或跟 Claude 說「這條不要」。
- **四個通用技能**，工作合適時 Claude 會自己用：`evidence-check`（寫數字結論、說某東西沒有或壞了之前）、`outward-docs`（替你寫要給別人看的文字之前）、`blind-three-way`（決定方向之前：各自獨立提方案再並排比）、`full-reader`（把很長的材料讀到最後一行，回報讀到哪）。

**會越用越長（而且是你的）：** 你自己的偏好，在你糾正、並說好之後才寫進去，永遠排在起始偏好上面；做對的做法補進對應的技能；同一種錯一直出現時加一個檢查；你的筆記和追蹤表。你沒同意的不會改，起始偏好也不會算成你的。

## 基本款和完整款

| | 基本款 | 完整款 |
|---|---|---|
| 對話 | 一個，在你的筆記資料夾裡 | 兩個固定的：**入口**（你唯一需要說話的對話）和**系統維護**（套件本身和每週的學習循環），再加上你的每件事各一個，由入口開、把事送進去 |
| 「做完了」誰核對 | Claude 附證據才關掉 | 主題對話回報給入口，入口打開證據核對；你收到一則結果 |
| 從使用中學習 | `learn_notice` 提醒 Claude 每次被糾正或確認做對都記一行；每週輕量整理，照類別提出偏好，你說好才寫；每件事動手前先讀偏好 | 一樣，改由系統維護對話做：偏好、技能，以及（只有同一種錯又出現時）新的檢查，都等你說好；每週一行趨勢 |
| 長對話 | Claude 寫好交接，你開新對話 | 一樣；在背景跑、太長又閒著的對話自動換新的接手 |
| 提醒 | 沒有 | 每週檢視、每月重新檢查你的外部資源、每天的交接檢查、你自己加的 |
| 外部資源 | 不用 | 只用你安裝時勾的（其他 AI、Colab 或 Kaggle、點數），依工作種類挑 |
| 適合 | 剛開始用；同時幾件事 | 好幾件事常被搞混、常忘記期限 |

完整款不是一個開關：每一項各自開，安裝時或之後說「幫我開主題對話」都可以；說「回到基本款」就全部關掉，檔案留著。每一項並排比較：[進階功能.md〈基本款和完整款〉](進階功能.md#基本款和完整款)。

## 裝好之後怎麼用

在筆記資料夾裡打開 Claude，再用平常聊天的方式打字跟它說。進去的路有兩條，照你安裝時用的那一種：

- **Claude App：** 打開 Claude，點側邊欄上方的 **Code** 分頁。在輸入框下面那一排，點第一個控制項、選 **Local** 底下最上面那一項，再點旁邊的資料夾控制項，選 **Open folder…**，選你的筆記資料夾。下次要繼續，就在側邊欄點那個對話；**+ New** 用同樣的方式開新對話。
- **終端機：** 用 Claude 幫你做的捷徑；沒有捷徑也行：打開終端機，輸入 `cd` 和筆記資料夾的路徑，再輸入 `claude`（`claude --continue` 會回到上一段對話）。

然後說，例如：

- 「記住：我這週要讀完第三章。」
- 「找我之前記的線性代數筆記。」
- 「還有什麼沒做完？」
- 「接著上次的專案報告繼續。」

## 什麼時候會建議加開

Claude 不會自己加功能。大約每週一次，一個小程式在你的電腦上看下面這些狀況。看的是你**真的遇到的麻煩**，不是事情多不多。某一項成立時，Claude 會附上數字問你一句「要不要開？」，你說好才開；你說不要，四週內不會再問同一項。

- 一週內你有兩次以上跟 Claude 說事情搞混了（例如「你把兩個作業搞混了」「不是那個專案」） → 完整款的對話：你說話的入口、系統維護，再加上一件事一個對話（主題對話）。追蹤表裡有幾件事、分幾個主題，會一起附上給你參考。入口會把每件事直接送進負責的主題對話，需要時把它叫起來，不超過你方案的上限；結果由入口告訴你。背景對話跑不起來的地方（例如只有桌面 App），入口會告訴你要打開哪個對話。
- 一週內你請 Claude 提醒你兩次以上，或有期限的事過了日期三天還沒做完 → 提醒。
- Claude 沒看結果就說「做完」的情況，已經記了兩週以上、至少 20 次，而且每四次裡至少三次你後來真的說有問題 → 問你要不要讓它直接被攔下、先去檢查。
- 你跟 Claude 說過你有外部資源（其他 AI 帳號、Colab、Kaggle、雲端點數） → 一張依工作種類分工的表。只是在對話裡提到名字不算。

任何一項（還有用量提醒：Claude 每週用量快用完時提醒你）你也可以隨時直接要。詳細說明在 [docs/zh-TW/進階功能.md](進階功能.md)，裡面還有基本款和完整款的完整比較表，以及六張圖說明各部分怎麼搭在一起。
